# OpenAPI Specs

## Overview
Late provides free, downloadable OpenAPI 3.0 specifications for major social media platforms enabling SDK generation, API client creation, and integration testing.

## Available Specs
- Twitter / X API
- Instagram Graph API
- Facebook Graph API
- LinkedIn API
- TikTok API
- YouTube Data API
- Pinterest API
- Reddit API
- Threads API
- Bluesky API (AT Protocol)
- Google Business Profile API
- Telegram Bot API
- Snapchat Marketing API

## Usage
- Import into Postman for API testing
- Generate SDKs with OpenAPI Generator
- Deploy Swagger UI for interactive docs

## GitHub Repository
All specifications maintained at github.com/getlate-dev/openapi-specs
